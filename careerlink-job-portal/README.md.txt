# CareerLink Job Portal

CareerLink is a full-stack job portal web application with user authentication, job listings, job applications, contact forms, and an Express/MySQL backend.

## Features

- User registration and login
- Job listing display
- Job search
- Job applications
- Admin page
- Contact form
- Resume/CV upload support
- REST API backend using Express
- MySQL database connection

## Technologies Used

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Node.js
- Express.js
- MySQL
- JSON Web Tokens
- bcrypt
- multer
- cors
- dotenv
